# MathSpark

Math activities for my students. Each topic has its own link:

- Parts and wholes: https://jameslazona.github.io/mathspark/parts-and-wholes/
- The part-whole model: https://jameslazona.github.io/mathspark/part-whole-model/

## Results
Open `config.js`, paste the Google Form pre-filled link into `formUrl`, and commit.

## Adding a new topic
1. In MathSpark on claude.ai, open the activity and press **⬇ Offline copy**.
2. Here on GitHub: **Add file → Upload files**. Rename the file to `index.html` and put it in a new folder, e.g. `number-bonds/index.html`.
3. The link is https://jameslazona.github.io/mathspark/number-bonds/
